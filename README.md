CasaVibe 🏠

About The Project

CasaVibe is a modern furniture e-commerce website designed to make furniture shopping simple, organized, and enjoyable.

The website allows users to explore different furniture products, view detailed product information, save favorite products, add products to a shopping cart, change product quantities, remove products, and complete an order through the checkout page.

The website focuses on providing a clean, elegant, and modern shopping experience.

---

💡 Project Idea

The main idea behind CasaVibe is to create an online furniture store where customers can easily discover furniture for different parts of their homes.

Instead of visiting different stores or searching through many websites, users can browse furniture in one organized website and quickly find products based on their category.

---

🎯 Target Users

CasaVibe is designed for:

- People looking for home furniture
- People interested in interior design
- Customers who prefer online shopping
- People looking for modern and stylish furniture

---

✨ Main Features

🛍️ Product Shopping

- Browse furniture products
- View products by category
- Search for products
- View product prices and images
- Open a detailed product page

❤️ Wishlist

- Add products to wishlist
- Remove products from wishlist
- View saved products
- Add wishlist products directly to the cart

🛒 Shopping Cart

- Add products to cart
- Increase product quantity
- Decrease product quantity
- Remove products from cart
- Automatically calculate subtotal
- Automatically calculate total price

💳 Checkout

- Enter customer information
- Enter delivery address
- Select payment method
- Review order items
- Place an order

👤 User System

- Login page
- Register page
- Store user information using LocalStorage
- Display the logged-in user's name

▶️ How To Run The Project

1. Download or clone the project from GitHub.
2. Open the project folder.
3. Open the "html" folder.
4. Open "index.html" in a web browser.

For a better development experience, the project can also be opened using VS Code and run with Live Server.
